## 2. 生产服务运行态

本地生产服务：`PORT=4181 npm start`。

已验证：

- `/api/health` 返回 200，并包含 `x-request-id`、`nosniff`、同源资源策略和相机/麦克风权限策略。
- 普通 API 返回 `ratelimit-limit: 80`，模型 API 返回 `ratelimit-limit: 30`。
- `/api/case-retrieval/preview` 返回 Top-K、正反例角色、分项分数、共同证据和 `server-timing`；黄焖鸡样例检索耗时 9ms。
- 非法 JSON 返回 400 和 request ID，不返回错误栈。
- 生产模式无有效 Key 时，规划接口返回脱敏 503，不暴露上游详情。
- `too_many_missing` 反馈可写入独立 QA 用户，并生成“优先使用现有库存”短期 trait。
- `DATA_DIR` 可覆盖运行时 `local-users` 写入根目录；演示种子、视觉缓存和 Case 库仍从镜像内读取。
- 发布冒烟脚本已固化到 `scripts/run-release-smoke.mjs`，同一命令可在公网部署后复用；设置 `REQUIRE_API_KEY=true` 时会额外要求服务已读取到 Key。
