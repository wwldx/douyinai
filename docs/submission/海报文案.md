## 主标题

刷到想吃的，看看家里能不能做

## 副标题

菜图 + 冰箱 + 一句话，AI 帮你完成今晚这一餐。

## 一句话介绍

上传抖音 Feed 中想吃的菜，再拍一下冰箱；AI 识别目标与库存，结合时间、厨艺和口头约束，给出现在怎么做、还差什么和下一步行动。

## 三步体验

1. 刷到想吃的菜，上传画面或说出要求。
2. 拍冰箱，确认真实可用食材。
3. 得到步骤、关键缺料、简化路线和安全提醒。

## 核心卖点

- 视觉不只识别菜名，还理解现实库存和不确定项。
- 语音适合补充“只有 25 分钟”“不想洗锅”等即时约束。
- 缺关键主料时不硬凑成原菜，给明确的替代或补齐路线。
- 缺料才出现抖音商城入口，做好后再生成生活记录。
- 结构化 Agent Workflow、固定评测集和开发检验台共同证明链路可运行。

## 可验证证据口径

- React H5 与 Node API 已通过同一 HTTPS 公网地址部署，固定示例可直接体验。
- 视觉、规划和生活记录三类任务当前统一使用 `gpt-5.6-terra` 稳定路由。
- 当前固定 30 例真实模型回归为 30/30，其中包含 11 例视觉和 19 例规划与安全用例；这只是固定回归结果，不代表真实用户准确率或线上分布。
- 历史 Case 检索已完成真实 A/B/C 实验；小样本未测得质量增益且增加 token，因此公网实验保持关闭。
- “番茄炒蛋太稀”等固定救援画面是明确标注的 AI 生成演示素材，不描述为真实用户照片或真实用户评测。
- 当前部署版本的 iPhone 相机、语音和权限降级仍待定向复验；不沿用旧版本真机证据冒充当前版本结论。
