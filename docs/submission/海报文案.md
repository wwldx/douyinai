# 海报文案：冰箱晚餐 Agent

## 主标题

冰箱晚餐 Agent

## 副标题

拍一下冰箱，AI 帮你决定今晚吃什么。

## 一句话介绍

从冰箱照片识别可用食材，结合厨艺、偏好、时间和精力，生成一顿现实可执行的晚餐方案。

## 展示文案

你打开冰箱时，真正想知道的不是“里面有什么”，而是：

- 这些东西能不能凑出一顿饭？
- 25 分钟内来不来得及？
- 新手会不会翻车？
- 缺一点材料，是补买、换菜，还是直接外卖？

冰箱晚餐 Agent 会先看懂冰箱照片，再让你快速确认库存，最后给出保底菜、进阶菜、缺料清单和兜底方案。

## 核心卖点

- 视觉识别食材、速食、饮料和包装线索。
- 对遮挡和不确定物品保守标注，不硬编。
- 根据厨艺、时间、精力和偏好生成晚餐决策。
- 新手默认低风险方案，避开复杂刀工和油炸。
- 缺料只推荐关键补买项，必要时给外卖兜底。

## Demo 标语

不是识别冰箱里有什么，  
而是帮你决定今晚怎么吃。

## 现场引导语

选择一张冰箱样例，取消一个核心食材，看看 AI 如何重新判断今晚该做饭、补买还是兜底。

## 分享短句

我刚让 AI 看了一眼冰箱，它没有给我十页菜谱，而是直接告诉我今晚最现实的一顿饭。
